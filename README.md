Ejercicio 7: Inventario por cantidad
Consiste en crear un arreglo de objetos Producto. Utilizar Insertion Sort para ordenar los productos según su cantidad disponible es la condición principal de este ejercicio, además, el programa deberá: 
Ordenar de menor a mayor, identificar productos agotados, mostrar primero los productos con menor existencia, contabilizar desplazamientos realizados por el algoritmo, realizar pruebas con un inventario inicialmente casi ordenado.

Desarrollado en java con Open oracle jdk 25.0.2 Build: Maven Language level: SDK defaul
